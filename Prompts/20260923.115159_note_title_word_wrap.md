# User Prompt
```text
In the notes list, in each card the Note title is displayed.  Make it word wrappable, 
```

## Implementation Walkthrough

- Modified `app/src/main/res/layout/item_tree_node.xml`.
- Removed `android:maxLines="1"` and `android:ellipsize="end"` attributes from the `textNodeTitle` TextView.
- This allows the note title text to naturally word-wrap across multiple lines within the list card when the text is too long to fit in a single line.
