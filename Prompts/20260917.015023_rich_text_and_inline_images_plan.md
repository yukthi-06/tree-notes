# Implementation Plan: Rich Text & Inline Images for Notes

Currently, the Notes section in `NodeEditorActivity` is a plain `EditText`. To support rich text with inline images, we will replace the `EditText` with a Rich Text Editor component that can output and render HTML.

## Proposed Changes

### Dependencies
- Added the `jp.wasabeef:richeditor-android:2.0.0` library to `app/build.gradle`.

### Layout (`activity_node_editor.xml`)
- Replaced the `EditText` (`@id/editNodeContent`) with a `jp.wasabeef.richeditor.RichEditor` component.
- Added a horizontal `LinearLayout` above the editor to act as a formatting toolbar.
- Added buttons to this toolbar: Bold, Italic, Add Image.

### Activity (`NodeEditorActivity.java`)
- Initialize the `RichEditor` and load `targetNode.getContent()` (which is treated as HTML).
- Enabled WebSettings for file access inside the RichEditor so local `file://` images can be rendered.
- Implemented an image picker using `ActivityResultLauncher<Intent>`.
- When an image is picked:
  - Extract the original filename using `ContentResolver` (or URI path).
  - Copy the selected image from the provided URI to the app's external storage (`storageManager.getResolvedStorageDir() + "/attachments"`).
  - If a file with the original name exists, append `_1`, `_2` to avoid conflicts.
  - Insert the local image URI into the `RichEditor` using `editor.insertImage("file://" + localFile.getAbsolutePath(), "image")`.
- When saving:
  - Retrieve the HTML content using `editor.getHtml()` and save it to `targetNode.setContent()`.

## Verification
- Verify formatting applies correctly.
- Verify images are copied to `/sdcard/Vypeensoft/Tree_Notes/attachments/`.
- Verify images render correctly in the editor and survive save/load cycles.
